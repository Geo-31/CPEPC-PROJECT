Notes

Study notes

Electrical circuits

For a series circuit, the same current flows through every component. Add the resistances to find the total resistance.

Review before the next problem set.

Data structures

A linked list stores items in nodes. Each node points to the next node, so inserting or removing an item does not require shifting every later item.

Remember to trace the pointer changes.

Web development

Use semantic HTML elements to describe the purpose of each part of a page, and keep form labels connected to their controls.
